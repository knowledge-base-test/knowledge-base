Оператор `not` используется для логического отрицания.

Он инвертирует логическое значение:

- `True` → `False`
- `False` → `True`

## Синтаксис

```python
not expression
```

где `expression` — логическое выражение, переменная или результат операции сравнения.

## Как работает

### С логическими значениями

```python
print(not True)
print(not False)
```

Результат:

```text
False
True
```

### С операторами сравнения

Чаще всего `not` используется перед выражением сравнения.

```python
print(not 10 > 5)
print(not 10 == 5)
```

Результат:

```text
False
True
```

### С переменными

```python
result = True

print(not result)
```

Результат:

```text
False
```

### С оператором принадлежности

`not` можно использовать вместе с оператором `in`:

```python
text = "Python"

print("Java" not in text)
print("Py" not in text)
```

Результат:

```text
True
False
```

## Особенности

Оператор `not` всегда возвращает значение типа `bool`.

Он имеет более высокий приоритет, чем логические операторы `and` и `or`, но применяется к результату выражения, которое стоит после него.

`if`, `elif` и `else` — инструкции (statements), которые позволяют выполнять разные блоки кода в зависимости от выполнения некоторого условия.

После `if` и `elif` обязательно записывается условие и ставится двоеточие (`:`).

После `else` условие не пишется.

Все инструкции имеют следующий синтаксис:

```python
if условие:
    блок кода

elif условие:
    блок кода

else:
    блок кода
```

Код внутри каждого блока должен иметь отступ в **4 пробела**.

## Как работают

### if

`if` означает «если».

Если условие истинно (`True`), выполняется блок кода.

```python
age = 20

if age >= 18:
    print("Совершеннолетний")
```

Условие:

```python
age >= 18
```

оценивается как `True`, поэтому код выполняется.

---

### elif

`elif` означает «иначе если».

Он позволяет проверить дополнительное условие, если предыдущие условия оказались ложными.

```python
score = 75

if score >= 90:
    print("Отлично")
elif score >= 60:
    print("Хорошо")
```

Первое условие оказалось ложным, поэтому Python проверяет второе.

---

### else

`else` означает «во всех остальных случаях».

Его блок выполняется только тогда, когда ни одно из предыдущих условий не оказалось истинным.

```python
score = 40

if score >= 90:
    print("Отлично")
elif score >= 60:
    print("Хорошо")
else:
    print("Не сдал")
```

Поскольку оба условия ложные, выполняется блок `else`.

## Что может быть условием

Условием может быть **любое выражение**.

Python всегда преобразует результат этого выражения к логическому типу (`bool`).

Если получается `True`, соответствующий блок кода выполняется.

Например:

```python
if 10 > 5:
    print("Истина")
```

```python
if "Py" in "Python":
    print("Найдено")
```

```python
if 10:
    print("Число не равно нулю")
```

Во всех этих примерах выражение оценивается как `True`.

## Особенности

Каждому `if`, `elif` и `else` соответствует свой блок кода с одинаковым уровнем отступа.

Проверка условий происходит сверху вниз.

После выполнения первого истинного условия остальные условия уже не проверяются.

`else` всегда располагается последним и не имеет собственного условия.

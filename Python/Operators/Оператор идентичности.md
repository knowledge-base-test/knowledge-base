Оператор `is` используется для проверки, являются ли две переменные ссылками на один и тот же объект в памяти.

Результатом проверки всегда является значение типа `bool`:

- `True`
- `False`

В отличие от оператора `==`, оператор `is` **не сравнивает значения объектов**, а проверяет, имеют ли они одинаковую идентичность (одинаковый `id`).

## Синтаксис

```python
object1 is object2
```

## Чем отличается от `==`

Оператор `==` сравнивает значения объектов.

```python
print([1, 2] == [1, 2])
```

Результат:

```text
True
```

Оператор `is` сравнивает не значения, а сами объекты.

```python
print([1, 2] is [1, 2])
```

Результат:

```text
False
```

Несмотря на одинаковое содержимое, это два разных объекта в памяти.

## Как работает

Если две переменные ссылаются на один объект:

```python
numbers = [1, 2, 3]
copy = numbers

print(numbers is copy)
```

Результат:

```text
True
```

Обе переменные содержат ссылку на один и тот же объект.

Если создать новый объект с таким же значением:

```python
numbers = [1, 2, 3]
copy = [1, 2, 3]

print(numbers is copy)
```

Результат:

```text
False
```

Объекты имеют одинаковые значения, но находятся в разных местах памяти.

## Связь с `id()`

Фактически оператор `is` проверяет, совпадают ли идентификаторы объектов.

```python
numbers = [1, 2, 3]
copy = numbers

print(id(numbers))
print(id(copy))
print(numbers is copy)
```

Идентификаторы будут одинаковыми, поэтому результатом станет `True`.

## Особенности

Оператор `is` всегда возвращает значение типа `bool`.

Используйте `==`, когда необходимо сравнить значения объектов.

Используйте `is`, когда необходимо проверить, являются ли две переменные ссылками на один и тот же объект.

Наиболее частый случай использования — сравнение с `None`:

```python
if value is None:
    print("Значение отсутствует")
```

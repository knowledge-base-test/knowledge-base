Оператор `in` используется для проверки, содержится ли одно значение внутри другого объекта.

Результатом проверки всегда является значение типа `bool`:

- `True`
- `False`

## Синтаксис

```python
value in object
```

где:

- `value` — то, что необходимо найти;
- `object` — объект, в котором выполняется поиск.

## Как работает

Для строк оператор проверяет, встречается ли одна строка внутри другой.

Например:

```python
print("Py" in "Python")
print("thon" in "Python")
print("Java" in "Python")
```

Результат:

```text
True
True
False
```

Последовательность символов имеет значение.

Например:

```python
print("abc" in "abcdef")
print("acb" in "abcdef")
```

Результат:

```text
True
False
```

Во втором случае символы есть, но расположены в другом порядке, поэтому результат — `False`.

Проверка чувствительна к регистру:

```python
print("python" in "Python")
print("Python" in "Python")
```

Результат:

```text
False
True
```

Оператор можно использовать вместе с переменными:

```python
text = "Hello, world!"

print("world" in text)
```

Результат:

```text
True
```

## Особенности

Оператор `in` возвращает значение типа `bool`.

Он работает не только со строками, но и со многими другими объектами Python, например списками, кортежами, словарями и множествами.

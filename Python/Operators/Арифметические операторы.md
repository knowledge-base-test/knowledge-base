## Операторы

- `+` — сложение.
- `-` — вычитание.
- `*` — умножение.
- `**` — возведение в степень.
- `/` — деление.
- `//` — целочисленное деление (возвращает только целую часть результата).
- `%` — остаток от деления.
- `@` — матричное умножение.

## Примеры

```python
12 // 5
# 2
```

Получилось разделить только число 10, поэтому результат — `2`.

```python
12 % 5
# 2
```

Остаток после деления — `2`.

```python
11 % 5
# 1
```

Остаток после деления — `1`.

## Приоритет выполнения

Операторы выполняются в следующем порядке:

1. `**` — возведение в степень.
2. `*`, `/`, `//`, `%`, `@` — умножение, деление, целочисленное деление, остаток от деления и матричное умножение.
3. `+`, `-` — сложение и вычитание.

Круглые скобки `()` позволяют изменить порядок вычислений. Выражения в скобках выполняются первыми.

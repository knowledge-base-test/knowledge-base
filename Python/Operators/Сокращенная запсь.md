Сокращённая запись используется, когда значение переменной изменяется с помощью [[Арифметические операторы]], а результат снова присваивается этой же переменной.

Обычная запись:

```python
count = 1
count = count + 1
```

Сокращённая запись:

```python
count = 1
count += 1
```

Обе записи увеличивают значение `count` на `1`.

В сокращённой записи арифметический оператор ставится перед знаком присваивания `=`:

```python
count += 1
count -= 1
count *= 2
count /= 2
```

Запись

```python
count += 1
```

можно прочитать так:

> взять текущее значение `count`, прибавить к нему `1` и связать имя `count` с полученным результатом.

Сокращённая запись работает и со строками. Оператор `+` соединяет строки:

```python
text = "Hello"
text += " world"

print(text)
```

Результат:

```text
Hello world
```

Добавляемая строка всегда располагается после исходной. С помощью `+=` нельзя поставить новую строку перед уже существующей.

Для добавления строки в начало нужна обычная запись:

```python
text = "world"
text = "Hello " + text
```

Результат:

```text
Hello world
```

Операторы `and` и `or` используются для объединения нескольких выражений в одно.

Их часто называют **логическими операторами**.

Особенность Python заключается в том, что эти операторы возвращают **не обязательно значение типа `bool`**, а один из своих операндов.

## Оператор `and`

### Что делает

Оператор `and` возвращает **первый операнд, который имеет значение `False`**, а если все операнды истинны — возвращает **последний операнд**.

Логически выражение с `and` считается истинным только тогда, когда **все операнды истинны**.

### Как работает

```python
print(True and True)
print(True and False)
```

Результат:

```text
True
False
```

Однако оператор возвращает сами значения:

```python
print(10 and 20)
```

Результат:

```text
20
```

Оба значения считаются истинными, поэтому возвращается последнее.

Если встретилось ложное значение:

```python
print(10 and 0 and 20)
```

Результат:

```text
0
```

Как только найден первый ложный операнд, дальнейшая проверка прекращается, и именно он становится результатом выражения.

## Оператор `or`

### Что делает

Оператор `or` возвращает **первый операнд, который имеет значение `True`**, а если все операнды ложны — возвращает **последний операнд**.

Логически выражение с `or` считается истинным, если **хотя бы один операнд истинный**.

### Как работает

```python
print(True or False)
print(False or False)
```

Результат:

```text
True
False
```

При работе с другими значениями:

```python
print(0 or 15)
```

Результат:

```text
15
```

Первое значение ложное, поэтому оператор возвращает первое истинное.

Если первое значение уже истинно:

```python
print(10 or 20)
```

Результат:

```text
10
```

Проверка дальше не выполняется.

Если все значения ложные:

```python
print(0 or "" or None)
```

Результат:

```text
None
```

Возвращается последний операнд.

## Особенности

Операторы `and` и `or` используют **ленивые вычисления** (short-circuit evaluation).

- `and` прекращает вычисление после первого ложного операнда.
- `or` прекращает вычисление после первого истинного операнда.

Благодаря этому они могут возвращать не только `True` и `False`, но и любые другие значения.

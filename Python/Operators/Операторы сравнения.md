Операторы сравнения используются для сравнения двух значений.

Результатом любого сравнения всегда является значение типа `bool`:

- `True`
- `False`

## Основные операторы

| Оператор | Описание |
|----------|----------|
| `==` | равно |
| `!=` | не равно |
| `>` | больше |
| `<` | меньше |
| `>=` | больше или равно |
| `<=` | меньше или равно |

## Как работают

### Проверка на равенство

```python
print(10 == 10)
print(10 == 5)
```

Результат:

```text
True
False
```

### Проверка на неравенство

```python
print(10 != 5)
print(10 != 10)
```

Результат:

```text
True
False
```

### Больше и меньше

```python
print(10 > 5)
print(10 < 5)
```

Результат:

```text
True
False
```

### Больше или равно

```python
print(10 >= 10)
print(10 >= 15)
```

Результат:

```text
True
False
```

### Меньше или равно

```python
print(5 <= 10)
print(5 <= 3)
```

Результат:

```text
True
False
```

## Сравнение строк

Строки также можно сравнивать.

Проверка на равенство работает ожидаемо:

```python
print("Python" == "Python")
print("Python" == "python")
```

Результат:

```text
True
False
```

Операторы `<`, `>`, `<=` и `>=` сравнивают строки посимвольно по числовым кодам символов (Unicode).

Например:

```python
print("A" < "B")
print("apple" < "banana")
print("a" > "A")
```

Результат:

```text
True
True
True
```

Сравнение происходит слева направо. Как только находятся разные символы, сравниваются их числовые коды.

## Особенности

Результатом любого оператора сравнения является значение типа `bool`.

```python
result = 10 > 5

print(type(result))
```

Результат:

```text
<class 'bool'>
```

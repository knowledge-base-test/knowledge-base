`math.ceil()` — функция модуля `math`, которая всегда округляет число **в большую сторону** до ближайшего целого числа.

Общий синтаксис:

```python
math.ceil(x)
```

где `x` — число, которое необходимо округлить.

---

## Как работает

Функция всегда возвращает **наименьшее целое число, которое больше или равно переданному числу**.

Например:

```python
import math

print(math.ceil(3.1))
print(math.ceil(3.9))
print(math.ceil(3.0))
```

Результат:

```text
4
4
3
```

Для отрицательных чисел:

```python
import math

print(math.ceil(-3.1))
```

Результат:

```text
-3
```

Несмотря на то, что число стало меньше по модулю, оно всё равно округлилось в большую сторону, потому что `-3` больше, чем `-3.1`.

---

## Особенности

Функция возвращает объект типа `int`.

Передавать в `math.ceil()` можно:
- число;
- переменную;
- выражение.

Например:

```python
import math

number = 2.4

print(math.ceil(number))
print(math.ceil(10 / 3))
```

Для использования функции необходимо сначала импортировать модуль `math`:

```python
import math
```

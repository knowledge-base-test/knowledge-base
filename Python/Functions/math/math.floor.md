`math.floor()` — функция модуля `math`, которая всегда округляет число **в меньшую сторону** до ближайшего целого числа.

Синтаксис:

```python
math.floor(x)
```

где `x` — число, которое необходимо округлить.

## Как работает

Функция возвращает наибольшее целое число, которое меньше или равно переданному числу.

```python
import math

print(math.floor(3.1))
print(math.floor(3.9))
print(math.floor(3.0))
```

Результат:

```text
3
3
3
```

Для отрицательных чисел округление также выполняется в меньшую сторону:

```python
import math

print(math.floor(-3.1))
```

Результат:

```text
-4
```

Число `-4` меньше, чем `-3.1`, поэтому результатом будет `-4`, а не `-3`.

## Особенности

`math.floor()` возвращает значение типа `int`.

В функцию можно передавать число, переменную или выражение:

```python
import math

number = 5.8

print(math.floor(number))
print(math.floor(10 / 3))
```

Перед использованием функции необходимо импортировать модуль `math`:

```python
import math
```

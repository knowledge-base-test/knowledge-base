Методы этой группы связаны с преобразованием текстовых строк для хранения, передачи и сравнения.

## `encode()`

### Что делает

`encode()` кодирует строку и возвращает последовательность байтов.

Синтаксис:

```python
string.encode(encoding, errors)
```

где:

- `encoding` — используемая кодировка;
- `errors` — способ обработки символов, которые невозможно закодировать.

По умолчанию используется кодировка UTF-8:

```python
text = "Hello"

result = text.encode()

print(result)
print(type(result))
```

Результат:

```text
b'Hello'
<class 'bytes'>
```

Для кириллицы:

```python
text = "Привет"

result = text.encode("utf-8")

print(result)
```

Результатом будет байтовая последовательность, содержащая закодированные символы.

Строка и байтовая последовательность — разные значения:

```python
text = "Hello"
data = text.encode("utf-8")

print(type(text))
print(type(data))
```

Результат:

```text
<class 'str'>
<class 'bytes'>
```

Чтобы снова получить строку, используется метод `decode()` байтового объекта:

```python
text = "Привет"
data = text.encode("utf-8")
restored_text = data.decode("utf-8")

print(restored_text)
```

Результат:

```text
Привет
```

Для кодирования и декодирования должна использоваться совместимая кодировка.

## Что такое кодировка

Компьютер хранит данные в виде чисел и байтов. Кодировка определяет, каким последовательностям байтов соответствуют определённые символы.

UTF-8 — одна из наиболее распространённых кодировок. Она поддерживает:

- латинские буквы;
- кириллицу;
- математические символы;
- большое количество письменностей;
- эмодзи и другие символы Unicode.

Пример:

```python
text = "Python 🐍"

data = text.encode("utf-8")

print(data)
```

## Параметр `errors`

Параметр `errors` определяет поведение при невозможности закодировать символ.

По умолчанию используется:

```python
errors="strict"
```

При ошибке кодирования возникает исключение.

Другие варианты:

```python
errors="ignore"
```

Неподдерживаемые символы пропускаются.

```python
errors="replace"
```

Неподдерживаемые символы заменяются специальным символом.

Пример с кодировкой ASCII:

```python
text = "Hello Привет"

print(text.encode("ascii", errors="ignore"))
```

Результат:

```text
b'Hello '
```

Кириллические символы были удалены, потому что они не входят в ASCII.

Обычно не следует использовать `ignore`, если потеря информации нежелательна.

## `casefold()`

### Что делает

`casefold()` подготавливает строку Unicode для сравнения без учёта регистра:

```python
first = "Straße"
second = "STRASSE"

print(first.casefold() == second.casefold())
```

Результат:

```text
True
```

В отличие от `encode()`, метод `casefold()` не создаёт байтовый объект. Он возвращает новую строку.

Подробно метод рассмотрен в заметке [[Методы изменения регистра строк]].

## Обратный порядок символов

У строк нет отдельного метода для переворачивания.

Для этого используется срез:

```python
string[::-1]
```

Пример:

```python
text = "Python"

print(text[::-1])
```

Результат:

```text
nohtyP
```

Здесь:

- первое пустое значение означает начало строки;
- второе пустое значение означает конец строки;
- шаг `-1` означает движение справа налево.

Это операция со срезом, а не строковый метод.

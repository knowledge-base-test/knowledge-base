Методы этой группы позволяют:

- разделять одну строку на несколько частей;
- объединять несколько строк;
- разделять строку относительно определённого разделителя.

## `split()`

### Что делает

`split()` разделяет строку на части и возвращает список строк.

Синтаксис:

```python
string.split(separator, maxsplit)
```

Оба аргумента необязательны.

### Разделение по пробельным символам

Если разделитель не указан, строка разделяется по пробельным символам:

```python
text = "Python is a programming language"

print(text.split())
```

Результат:

```text
['Python', 'is', 'a', 'programming', 'language']
```

Несколько последовательных пробелов воспринимаются как один разделитель:

```python
text = "Python    programming"

print(text.split())
```

Результат:

```text
['Python', 'programming']
```

Также учитываются табуляция и переносы строк.

### Разделение по указанному символу

```python
text = "apple,banana,orange"

print(text.split(","))
```

Результат:

```text
['apple', 'banana', 'orange']
```

Если разделитель указан явно, несколько последовательных разделителей создают пустые строки:

```python
text = "apple,,orange"

print(text.split(","))
```

Результат:

```text
['apple', '', 'orange']
```

### Ограничение количества разделений

Аргумент `maxsplit` определяет максимальное количество разделений:

```python
text = "one two three four"

print(text.split(" ", 2))
```

Результат:

```text
['one', 'two', 'three four']
```

Было выполнено не более двух разделений.

## `rsplit()`

### Что делает

`rsplit()` работает аналогично `split()`, но при использовании `maxsplit` выполняет разделение справа.

Синтаксис:

```python
string.rsplit(separator, maxsplit)
```

Пример:

```python
text = "one two three four"

print(text.rsplit(" ", 2))
```

Результат:

```text
['one two', 'three', 'four']
```

Сравнение:

```python
text = "one two three four"

print(text.split(" ", 2))
print(text.rsplit(" ", 2))
```

Результат:

```text
['one', 'two', 'three four']
['one two', 'three', 'four']
```

Без ограничения `maxsplit` методы `split()` и `rsplit()` обычно дают одинаковый результат.

## `splitlines()`

### Что делает

`splitlines()` разделяет многострочную строку по границам строк.

Синтаксис:

```python
string.splitlines()
```

Пример:

```python
text = "line1\nline2\nline3"

print(text.splitlines())
```

Результат:

```text
['line1', 'line2', 'line3']
```

Можно сохранить символы переноса строк:

```python
text = "line1\nline2\nline3"

print(text.splitlines(keepends=True))
```

Результат:

```text
['line1\n', 'line2\n', 'line3']
```

## `join()`

### Что делает

`join()` объединяет строки из итерируемого объекта, используя исходную строку как разделитель.

Синтаксис:

```python
separator.join(iterable)
```

Пример:

```python
words = ["Python", "is", "useful"]

result = " ".join(words)

print(result)
```

Результат:

```text
Python is useful
```

Разделителем может быть любая строка:

```python
words = ["one", "two", "three"]

print("-".join(words))
print(", ".join(words))
print("".join(words))
```

Результат:

```text
one-two-three
one, two, three
onetwothree
```

Все объединяемые элементы должны быть строками.

Такой код вызовет ошибку:

```python
values = ["age", 21]

print(" ".join(values))
```

Для объединения чисел их сначала необходимо преобразовать в строки:

```python
values = [10, 20, 30]

result = ", ".join(map(str, values))

print(result)
```

Результат:

```text
10, 20, 30
```

## `partition()`

### Что делает

`partition()` разделяет строку на три части относительно первого вхождения указанного разделителя.

Синтаксис:

```python
string.partition(separator)
```

Метод возвращает кортеж из трёх элементов:

1. часть до разделителя;
2. сам разделитель;
3. часть после разделителя.

```python
text = "name:Danil"

print(text.partition(":"))
```

Результат:

```text
('name', ':', 'Danil')
```

Если разделитель не найден:

```python
text = "name Danil"

print(text.partition(":"))
```

Результат:

```text
('name Danil', '', '')
```

Результат можно распаковать:

```python
text = "name:Danil"

key, separator, value = text.partition(":")

print(key)
print(value)
```

Результат:

```text
name
Danil
```

## `rpartition()`

### Что делает

`rpartition()` разделяет строку на три части относительно последнего вхождения разделителя.

Синтаксис:

```python
string.rpartition(separator)
```

Пример:

```python
path = "folder/subfolder/file.txt"

print(path.rpartition("/"))
```

Результат:

```text
('folder/subfolder', '/', 'file.txt')
```

Если разделитель отсутствует:

```python
print("file.txt".rpartition("/"))
```

Результат:

```text
('', '', 'file.txt')
```

### Сравнение `partition()` и `rpartition()`

`partition()` ищет первое вхождение разделителя.

`rpartition()` ищет последнее вхождение разделителя.

```python
text = "one-two-three"

print(text.partition("-"))
print(text.rpartition("-"))
```

Результат:

```text
('one', '-', 'two-three')
('one-two', '-', 'three')
```

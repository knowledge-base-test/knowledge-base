Методы этой группы возвращают новые строки с удалёнными, заменёнными или преобразованными символами.

Исходная строка остаётся неизменной.

## `replace()`

### Что делает

`replace()` заменяет вхождения одной подстроки другой подстрокой.

Синтаксис:

```python
string.replace(old, new, count)
```

где:

- `old` — заменяемая подстрока;
- `new` — новая подстрока;
- `count` — максимальное количество замен.

Пример:

```python
text = "I like cats"

print(text.replace("cats", "dogs"))
```

Результат:

```text
I like dogs
```

По умолчанию заменяются все вхождения:

```python
text = "one one one"

print(text.replace("one", "two"))
```

Результат:

```text
two two two
```

Количество замен можно ограничить:

```python
text = "one one one"

print(text.replace("one", "two", 2))
```

Результат:

```text
two two one
```

Метод можно использовать для удаления подстроки, заменив её пустой строкой:

```python
text = "Hello, world!"

print(text.replace(",", ""))
```

Результат:

```text
Hello world!
```

## `strip()`

### Что делает

`strip()` удаляет символы с начала и конца строки.

Синтаксис:

```python
string.strip(chars)
```

Если аргумент не указан, удаляются пробельные символы:

```python
text = "   Hello world   "

print(text.strip())
```

Результат:

```text
Hello world
```

Пробелы внутри строки не удаляются:

```python
text = "   Hello   world   "

print(text.strip())
```

Результат:

```text
Hello   world
```

Можно указать набор удаляемых символов:

```python
text = "!!!Hello!!!"

print(text.strip("!"))
```

Результат:

```text
Hello
```

Аргумент рассматривается как набор отдельных символов, а не как цельная подстрока:

```python
text = "abcHello cab"

print(text.strip("abc "))
```

Результат:

```text
Hello
```

Метод удаляет любые символы из указанного набора, пока они встречаются по краям строки.

## `lstrip()`

### Что делает

`lstrip()` удаляет символы только с левого края строки.

Синтаксис:

```python
string.lstrip(chars)
```

Пример:

```python
text = "   Hello   "

print(text.lstrip())
```

Результат:

```text
Hello   
```

С указанными символами:

```python
text = "---Hello---"

print(text.lstrip("-"))
```

Результат:

```text
Hello---
```

## `rstrip()`

### Что делает

`rstrip()` удаляет символы только с правого края строки.

Синтаксис:

```python
string.rstrip(chars)
```

Пример:

```python
text = "   Hello   "

print(text.rstrip())
```

Результат:

```text
   Hello
```

С указанными символами:

```python
text = "---Hello---"

print(text.rstrip("-"))
```

Результат:

```text
---Hello
```

## `removeprefix()`

### Что делает

`removeprefix()` удаляет указанную подстроку с начала строки, если строка действительно с неё начинается.

Синтаксис:

```python
string.removeprefix(prefix)
```

Пример:

```python
text = "https://example.com"

print(text.removeprefix("https://"))
```

Результат:

```text
example.com
```

Если префикс отсутствует, строка возвращается без изменений:

```python
text = "example.com"

print(text.removeprefix("https://"))
```

Результат:

```text
example.com
```

В отличие от `lstrip()`, метод удаляет цельную подстроку:

```python
text = "abcabcHello"

print(text.removeprefix("abc"))
print(text.lstrip("abc"))
```

Результат:

```text
abcHello
Hello
```

## `removesuffix()`

### Что делает

`removesuffix()` удаляет указанную подстроку с конца строки, если строка действительно ею заканчивается.

Синтаксис:

```python
string.removesuffix(suffix)
```

Пример:

```python
filename = "report.pdf"

print(filename.removesuffix(".pdf"))
```

Результат:

```text
report
```

Если суффикс отсутствует, строка возвращается без изменений:

```python
filename = "report.txt"

print(filename.removesuffix(".pdf"))
```

Результат:

```text
report.txt
```

## `maketrans()`

### Что делает

`str.maketrans()` создаёт таблицу преобразований для метода `translate()`.

Синтаксис:

```python
str.maketrans(mapping)
```

или:

```python
str.maketrans(old, new)
```

Пример:

```python
table = str.maketrans({
    "a": "1",
    "e": "2",
    "i": "3"
})
```

Метод не преобразует строку сам, а только создаёт правила преобразования.

Можно передать две строки одинаковой длины:

```python
table = str.maketrans("abc", "123")
```

Это означает:

- `a` заменить на `1`;
- `b` заменить на `2`;
- `c` заменить на `3`.

Третий необязательный аргумент содержит символы, которые необходимо удалить:

```python
table = str.maketrans("abc", "123", "!")
```

## `translate()`

### Что делает

`translate()` преобразует строку по таблице, созданной с помощью `str.maketrans()`.

Синтаксис:

```python
string.translate(table)
```

Пример:

```python
table = str.maketrans("abc", "123")

text = "abcabc"

print(text.translate(table))
```

Результат:

```text
123123
```

Замена нескольких символов:

```python
table = str.maketrans({
    "a": "@",
    "e": "3",
    "o": "0"
})

text = "Hello world"

print(text.translate(table))
```

Результат:

```text
H3ll0 w0rld
```

Удаление символов:

```python
table = str.maketrans("", "", ".,!?")

text = "Hello, world!"

print(text.translate(table))
```

Результат:

```text
Hello world
```

### Сравнение `replace()` и `translate()`

`replace()` удобен для замены отдельных подстрок:

```python
text.replace("Python", "Java")
```

`translate()` удобен для одновременной замены или удаления большого количества отдельных символов.

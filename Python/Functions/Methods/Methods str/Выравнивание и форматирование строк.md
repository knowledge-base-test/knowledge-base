Методы этой группы позволяют:

- выравнивать текст;
- дополнять строку символами;
- заменять табуляцию пробелами;
- подставлять значения в строковый шаблон.

## `center()`

### Что делает

`center()` возвращает строку указанной длины, располагая исходный текст по центру.

Синтаксис:

```python
string.center(width, fillchar)
```

где:

- `width` — итоговая длина строки;
- `fillchar` — символ заполнения.

Пример:

```python
text = "Python"

print(text.center(12))
```

Результат:

```text
   Python   
```

По умолчанию используется пробел.

Можно указать другой символ:

```python
text = "Python"

print(text.center(12, "-"))
```

Результат:

```text
---Python---
```

Символ заполнения должен состоять ровно из одного символа:

```python
text.center(12, "--")
```

Такой вызов приведёт к ошибке.

Если указанная ширина меньше или равна длине строки, строка возвращается без изменений:

```python
print("Python".center(4, "-"))
```

Результат:

```text
Python
```

## `ljust()`

### Что делает

`ljust()` выравнивает строку по левому краю и добавляет символы справа.

Синтаксис:

```python
string.ljust(width, fillchar)
```

Пример:

```python
text = "Python"

print(text.ljust(12, "-"))
```

Результат:

```text
Python------
```

## `rjust()`

### Что делает

`rjust()` выравнивает строку по правому краю и добавляет символы слева.

Синтаксис:

```python
string.rjust(width, fillchar)
```

Пример:

```python
text = "Python"

print(text.rjust(12, "-"))
```

Результат:

```text
------Python
```

## `zfill()`

### Что делает

`zfill()` дополняет строку нулями слева до указанной длины.

Синтаксис:

```python
string.zfill(width)
```

Пример:

```python
number = "42"

print(number.zfill(5))
```

Результат:

```text
00042
```

Метод учитывает знак числа:

```python
print("-42".zfill(5))
print("+42".zfill(5))
```

Результат:

```text
-0042
+0042
```

Знак остаётся в начале строки, а нули добавляются после него.

`zfill()` работает со строками, а не с числами:

```python
number = 42

print(str(number).zfill(5))
```

Результат:

```text
00042
```

## `expandtabs()`

### Что делает

`expandtabs()` заменяет символы табуляции `\t` пробелами.

Синтаксис:

```python
string.expandtabs(tabsize)
```

По умолчанию размер позиции табуляции равен 8:

```python
text = "name\tage"

print(text.expandtabs())
```

Можно указать другой размер:

```python
text = "name\tage"

print(text.expandtabs(8))
print(text.expandtabs(12))
```

Количество добавленных пробелов зависит не только от `tabsize`, но и от текущего положения символа в строке.

Метод перемещает следующий текст к ближайшей позиции табуляции.

## `format()`

### Что делает

`format()` подставляет переданные значения в фигурные скобки внутри строки.

Синтаксис:

```python
template.format(values)
```

Пример с позиционными аргументами:

```python
template = "Name: {}, age: {}"

result = template.format("Danil", 21)

print(result)
```

Результат:

```text
Name: Danil, age: 21
```

Можно использовать номера аргументов:

```python
template = "{1} studies {0}"

print(template.format("Python", "Danil"))
```

Результат:

```text
Danil studies Python
```

Один аргумент можно использовать несколько раз:

```python
template = "{0} + {0} = {1}"

print(template.format(2, 4))
```

Результат:

```text
2 + 2 = 4
```

Можно использовать именованные аргументы:

```python
template = "Name: {name}, age: {age}"

print(template.format(name="Danil", age=21))
```

Результат:

```text
Name: Danil, age: 21
```

### Форматирование чисел

Ограничение количества знаков после точки:

```python
number = 3.1415926

print("{:.2f}".format(number))
```

Результат:

```text
3.14
```

Добавление разделителей разрядов:

```python
number = 1000000

print("{:,}".format(number))
```

Результат:

```text
1,000,000
```

Процентный формат:

```python
value = 0.875

print("{:.1%}".format(value))
```

Результат:

```text
87.5%
```

В современном Python для большинства случаев удобнее использовать f-строки:

```python
name = "Danil"
age = 21

print(f"Name: {name}, age: {age}")
```

## `format_map()`

### Что делает

`format_map()` подставляет значения из словаря или другого сопоставимого объекта.

Синтаксис:

```python
template.format_map(mapping)
```

Пример:

```python
data = {
    "name": "Danil",
    "age": 21
}

template = "Name: {name}, age: {age}"

print(template.format_map(data))
```

Результат:

```text
Name: Danil, age: 21
```

### Сравнение `format()` и `format_map()`

С `format()` словарь обычно передаётся с распаковкой:

```python
data = {
    "name": "Danil",
    "age": 21
}

print("Name: {name}, age: {age}".format(**data))
```

С `format_map()` словарь передаётся напрямую:

```python
print("Name: {name}, age: {age}".format_map(data))
```

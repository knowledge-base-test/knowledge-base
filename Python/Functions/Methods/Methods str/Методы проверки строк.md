Методы проверки анализируют содержимое строки и возвращают значение типа `bool`:

- `True`, если условие выполняется;
- `False`, если условие не выполняется.

Большинство подобных методов возвращает `False` для пустой строки:

```python
print("".isalpha())
print("".isdigit())
```

Результат:

```text
False
False
```

## `isidentifier()`

### Что делает

`isidentifier()` проверяет, может ли строка использоваться как идентификатор Python.

Идентификаторами являются имена переменных, функций, классов и других объектов.

Синтаксис:

```python
string.isidentifier()
```

Примеры:

```python
print("user_name".isidentifier())
print("age2".isidentifier())
print("2age".isidentifier())
print("user-name".isidentifier())
print("user name".isidentifier())
```

Результат:

```text
True
True
False
False
False
```

Метод проверяет форму идентификатора, но не проверяет, является ли строка ключевым словом Python:

```python
print("if".isidentifier())
```

Результат:

```text
True
```

Хотя `if` является ключевым словом и не может использоваться как имя переменной.

## `isdigit()`

### Что делает

`isdigit()` возвращает `True`, если строка:

- не пустая;
- состоит только из символов, которые Python считает цифрами.

Синтаксис:

```python
string.isdigit()
```

Примеры:

```python
print("12345".isdigit())
print("12.5".isdigit())
print("-10".isdigit())
print("123a".isdigit())
```

Результат:

```text
True
False
False
False
```

Точка и знак минуса не являются цифрами.

Некоторые надстрочные цифры также распознаются методом:

```python
print("²".isdigit())
```

Результат:

```text
True
```

## `isdecimal()`

### Что делает

`isdecimal()` возвращает `True`, если строка состоит только из десятичных цифровых символов.

Синтаксис:

```python
string.isdecimal()
```

Примеры:

```python
print("12345".isdecimal())
print("²".isdecimal())
```

Результат:

```text
True
False
```

`isdecimal()` имеет более строгие требования, чем `isdigit()` и `isnumeric()`.

## `isnumeric()`

### Что делает

`isnumeric()` возвращает `True`, если строка состоит только из числовых символов.

Синтаксис:

```python
string.isnumeric()
```

Метод распознаёт более широкий набор числовых символов, чем `isdigit()` и `isdecimal()`:

```python
print("123".isnumeric())
print("²".isnumeric())
print("⅕".isnumeric())
```

Результат:

```text
True
True
True
```

### Сравнение числовых проверок

От наиболее строгой проверки к наиболее широкой:

```text
isdecimal() → isdigit() → isnumeric()
```

Обычные цифры от `0` до `9` проходят все три проверки:

```python
text = "123"

print(text.isdecimal())
print(text.isdigit())
print(text.isnumeric())
```

Результат:

```text
True
True
True
```

`isalpha()` возвращает `True`, если строка:

- не пустая;

Синтаксис:

```python
string.isalpha()
```

```python
print("Python".isalpha())

```

Результат:

```text
True
True
False
False
```

## `isalnum()`

### Что делает

`isalnum()` возвращает `True`, если строка:

- не пустая;
- состоит только из букв и числовых символов.

Синтаксис:

```python
string.isalnum()
```

Примеры:

```python
print("Python3".isalnum())
print("Python".isalnum())
print("123".isalnum())
print("Python 3".isalnum())
print("Python-3".isalnum())
```

Результат:

```text
True
True
True
False
False
```

Пробелы и знаки препинания не считаются буквами или числами.

## `isascii()`

### Что делает

`isascii()` возвращает `True`, если все символы строки входят в таблицу ASCII.

Синтаксис:

```python
string.isascii()
```

К ASCII относятся:

- латинские буквы;
- цифры;
- основные знаки препинания;
- пробельные и управляющие символы ASCII.

Примеры:

```python
print("Hello 123!".isascii())
print("Привет".isascii())
```

Результат:

```text
True
False
```

Пустая строка также возвращает `True`:

```python
print("".isascii())
```

Результат:

```text
True
```

## `isspace()`

### Что делает

`isspace()` возвращает `True`, если строка:

- не пустая;
- состоит только из пробельных символов.

Синтаксис:

```python
string.isspace()
```

К пробельным символам относятся не только обычные пробелы, но также табуляция и перенос строки:

```python
print("   ".isspace())
print("\t".isspace())
print("\n".isspace())
print(" a ".isspace())
```

Результат:

```text
True
True
True
False
```

## `islower()`

### Что делает

`islower()` проверяет, находятся ли все буквы строки в нижнем регистре.

Синтаксис:

```python
string.islower()
```

Примеры:

```python
print("python".islower())
print("python 123!".islower())
print("Python".islower())
```

Результат:

```text
True
True
False
```

Цифры и специальные символы не учитываются при проверке регистра.

При этом строка должна содержать хотя бы одну букву:

```python
print("123".islower())
```

Результат:

```text
False
```

## `istitle()`

### Что делает

`istitle()` проверяет, записана ли строка в формате заголовка.

В таком формате каждое слово начинается с заглавной буквы, а остальные буквы слова находятся в нижнем регистре.

Синтаксис:

```python
string.istitle()
```

Примеры:

```python
print("Python Programming".istitle())
print("Python programming".istitle())
print("PYTHON PROGRAMMING".istitle())
```

Результат:

```text
True
False
False
```

## `isprintable()`

### Что делает

`isprintable()` возвращает `True`, если все символы строки являются печатаемыми или строка пустая.

Синтаксис:

```python
string.isprintable()
```

Примеры:

```python
print("Hello world!".isprintable())
print("Hello\nworld!".isprintable())
print("".isprintable())
```

Результат:

```text
True
False
True
```

Символ переноса строки `\n` является управляющим, а не печатаемым символом.

Обычный пробел считается печатаемым:

```python
print(" ".isprintable())
```

Результат:

```text
True
```

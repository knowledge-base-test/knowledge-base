Методы строк — это функции, принадлежащие значениям типа `str` и предназначенные для обработки текста.

Метод вызывается через точку после строки или переменной:

```python
text.method()
```

Некоторые методы принимают аргументы:

```python
text.method(argument)
```

Пример:

```python
text = "hello"

print(text.upper())
```

Результат:

```text
HELLO
```

## Строки неизменяемы

Строки относятся к неизменяемым типам данных. Поэтому строковые методы не изменяют исходную строку, а возвращают новое значение.

```python
text = "hello"

text.upper()

print(text)
```

Результат:

```text
hello
```

Чтобы сохранить результат, его необходимо присвоить переменной:

```python
text = "hello"
text = text.upper()

print(text)
```

Результат:

```text
HELLO
```

Методы, предназначенные для проверки строки, обычно возвращают значение типа `bool`.

```python
text = "Python"

print(text.isalpha())
```

Результат:

```text
True
```

Методы изменения регистра создают новую строку, в которой регистр букв изменён по определённому правилу.

Исходная строка при этом не изменяется.

```python
text = "Hello"

result = text.upper()

print(text)
print(result)
```

Результат:

```text
Hello
HELLO
```

## `capitalize()`

### Что делает

`capitalize()` возвращает копию строки, в которой:

- первый символ переводится в верхний регистр;
- остальные символы переводятся в нижний регистр.

Синтаксис:

```python
string.capitalize()
```

Пример:

```python
text = "hELLO WORLD"

print(text.capitalize())
```

Результат:

```text
Hello world
```

Метод изменяет регистр только первого символа всей строки, а не каждого слова:

```python
text = "python programming language"

print(text.capitalize())
```

Результат:

```text
Python programming language
```

## `lower()`

### Что делает

`lower()` возвращает копию строки, в которой все буквы переведены в нижний регистр.

Синтаксис:

```python
string.lower()
```

Пример:

```python
text = "Hello PYTHON"

print(text.lower())
```

Результат:

```text
hello python
```

Цифры, пробелы и специальные символы не изменяются:

```python
text = "Python 3.14!"

print(text.lower())
```

Результат:

```text
python 3.14!
```

## `upper()`

### Что делает

`upper()` возвращает копию строки, в которой все буквы переведены в верхний регистр.

Синтаксис:

```python
string.upper()
```

Пример:

```python
text = "Hello Python"

print(text.upper())
```

Результат:

```text
HELLO PYTHON
```

## `title()`

### Что делает

`title()` возвращает копию строки, в которой каждое слово начинается с заглавной буквы, а остальные буквы переводятся в нижний регистр.

Синтаксис:

```python
string.title()
```

Пример:

```python
text = "python programming language"

print(text.title())
```

Результат:

```text
Python Programming Language
```

Разделителями слов могут считаться не только пробелы, но и другие символы:

```python
text = "hello-world"

print(text.title())
```

Результат:

```text
Hello-World
```

## `swapcase()`

### Что делает

`swapcase()` меняет регистр каждой буквы на противоположный:

- строчные буквы становятся заглавными;
- заглавные буквы становятся строчными.

Синтаксис:

```python
string.swapcase()
```

Пример:

```python
text = "Hello PYTHON"

print(text.swapcase())
```

Результат:

```text
hELLO python
```

## `casefold()`

### Что делает

`casefold()` возвращает строку в регистре, предназначенном для сравнения текста без учёта регистра.

Синтаксис:

```python
string.casefold()
```

Для большинства латинских строк результат похож на `lower()`:

```python
text = "PYTHON"

print(text.lower())
print(text.casefold())
```

Результат:

```text
python
python
```

Однако `casefold()` выполняет более полное преобразование символов Unicode:

```python
text = "Straße"

print(text.lower())
print(text.casefold())
```

Результат:

```text
straße
strasse
```

Для сравнения пользовательского текста без учёта регистра обычно надёжнее использовать `casefold()`:

```python
first = "Straße"
second = "STRASSE"

print(first.casefold() == second.casefold())
```

Результат:

```text
True
```

### Сравнение `lower()` и `casefold()`

`lower()` предназначен прежде всего для перевода букв в нижний регистр.

`casefold()` предназначен для сравнения строк без учёта регистра и учитывает больше особенностей Unicode.

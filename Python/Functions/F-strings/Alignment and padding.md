Спецификаторы выравнивания определяют положение значения внутри поля заданной ширины.

Основные символы:

- `<` — выравнивание по левому краю;
- `>` — выравнивание по правому краю;
- `^` — выравнивание по центру.

Общая форма:

```python
f"{value:alignment_width}"
```

Например:

```python
f"{value:>10}"
```

означает: представить значение в поле шириной 10 символов и выровнять его вправо.

## Выравнивание по левому краю

```python
number = 42

print(f"{number:<5}")
```

Результат:

```text
42   
```

После числа добавляются три пробела, поэтому общая ширина составляет пять символов.

## Выравнивание по правому краю

```python
number = 42

print(f"{number:>5}")
```

Результат:

```text
   42
```

Перед числом добавляются три пробела.

Числовые значения по умолчанию выравниваются вправо:

```python
number = 42

print(f"{number:5}")
```

Результат:

```text
   42
```

У строк поведение по умолчанию другое: они выравниваются влево.

```python
text = "Hi"

print(f"{text:5}")
```

Результат:

```text
Hi   
```

Поэтому для явного правого выравнивания строки необходимо использовать `>`:

```python
print(f"{text:>5}")
```

Результат:

```text
   Hi
```

## Выравнивание по центру

```python
number = 42

print(f"{number:^6}")
```

Результат:

```text
  42  
```

Если свободное количество символов нельзя разделить поровну, дополнительный символ обычно размещается справа:

```python
print(f"{number:^5}")
```

Результат:

```text
 42  
```

## Символ заполнения

Перед символом выравнивания можно указать один символ, которым будет заполнено свободное место.

Общая запись:

```python
f"{value:fill_alignment_width}"
```

Пример:

```python
number = 42

print(f"{number:*^7}")
```

Результат:

```text
**42***
```

Разбор:

- `*` — символ заполнения;
- `^` — выравнивание по центру;
- `7` — общая ширина поля.

Другие примеры:

```python
print(f"{42:->7}")
print(f"{42:.<7}")
```

Результат:

```text
-----42
42.....
```

## Выравнивание чисел с точностью

Выравнивание можно комбинировать с количеством знаков после точки.

```python
pi = 3.14159265

print(f"{pi:>8.2f}")
print(f"{pi:<8.2f}")
print(f"{pi:^8.2f}")
```

Результат:

```text
    3.14
3.14    
  3.14  
```

Разбор записи:

```python
f"{pi:<8.2f}"
```

- `<` — выравнивание влево;
- `8` — общая ширина поля;
- `.2` — два знака после точки;
- `f` — десятичное представление с фиксированной точкой.

## Отображение знака

Символ `+` заставляет Python явно показывать знак как положительных, так и отрицательных чисел.

```python
positive = 42
negative = -42

print(f"{positive:+d}")
print(f"{negative:+d}")
```

Результат:

```text
+42
-42
```

Пробел перед спецификатором типа означает:

- положительные числа получают ведущий пробел;
- отрицательные числа сохраняют знак минуса.

```python
print(f"{positive: d}")
print(f"{negative: d}")
```

Результат:

```text
 42
-42
```

Это удобно для выравнивания положительных и отрицательных значений в столбце.

## Разделители разрядов

Запятая разделяет числовые группы по три цифры:

```python
number = 1234567890

print(f"{number:,}")
```

Результат:

```text
1,234,567,890
```

Подчёркивание можно использовать вместо запятой:

```python
print(f"{number:_}")
```

Результат:

```text
1_234_567_890
```

Разделители можно сочетать с точностью:

```python
number = 1234567.891

print(f"{number:,.2f}")
```

Результат:

```text
1,234,567.89
```

## Динамическая ширина

Ширину поля можно хранить в переменной:

```python
width = 10
number = 7

print(f"{number:{width}}")
```

Результат:

```text
         7
```

Можно динамически задавать одновременно выравнивание, ширину и точность:

```python
width = 10
precision = 2
number = 3.14159

print(f"{number:>{width}.{precision}f}")
```

Результат:

```text
      3.14
```

## Табличное форматирование

```python
print(f"{'Name':<10}{'Age':>5}")
print(f"{'Anna':<10}{23:>5}")
print(f"{'Daniel':<10}{7:>5}")
```

Результат:

```text
Name        Age
Anna         23
Daniel        7
```

Одинаковая ширина полей позволяет выстраивать значения в столбцы.

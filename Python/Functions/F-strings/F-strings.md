F-строки — это способ создавать строки, внутрь которых можно подставлять значения переменных и результаты выражений.

Перед открывающей кавычкой ставится буква `f`:

```python
name = "Danil"
age = 21

text = f"Меня зовут {name}, мне {age} год"

print(text)
```

Результат:

```text
Меня зовут Danil, мне 21 год
```

В фигурных скобках `{}` можно записывать:

- переменные;
- литералы;
- арифметические выражения;
- вызовы функций;
- обращения к элементам объектов;
- другие выражения Python.

```python
a = 10
b = 5

print(f"Сумма: {a + b}")
print(f"Длина строки: {len('Python')}")
```

Результат:

```text
Сумма: 15
Длина строки: 6
```

## Как работает

При выполнении f-строки Python:

1. вычисляет выражения внутри `{}`;
2. преобразует полученные значения в текст;
3. подставляет текст в соответствующие места;
4. создаёт новый объект типа `str`.

```python
number = 10

text = f"Число: {number * 2}"
```

Сначала вычисляется:

```python
number * 2
```

Получается объект `int` со значением `20`. Затем он преобразуется в текст и включается в новую строку:

```text
Число: 20
```

## Синтаксис

Общая форма:

```python
f"{expression}"
```

С указанием преобразования:

```python
f"{expression!conversion}"
```

С указанием форматирования:

```python
f"{expression:format_specifier}"
```

Одновременно с преобразованием и форматированием:

```python
f"{expression!conversion:format_specifier}"
```

## Спецификаторы форматирования

После выражения можно поставить двоеточие и указать правила его отображения:

```python
value = 3.14159

print(f"{value:.2f}")
```

Результат:

```text
3.14
```

В данном примере:

- `value` — форматируемое значение;
- `:` — начало спецификатора;
- `.2` — оставить два знака после точки;
- `f` — представить значение как число с фиксированной точкой.

Подробные правила находятся в заметках:

- [[Numeric format specifiers]]
- [[Alignment and padding]]
- [[F-string conversions and debugging]]
- [[Integer base formatting]]

## Вложенные выражения

Параметры форматирования также могут задаваться выражениями или переменными.

```python
width = 10
number = 7

print(f"{number:{width}}")
```

Результат представляет число в поле шириной 10 символов:

```text
         7
```

Можно динамически задавать и точность:

```python
precision = 3
number = 3.14159265

print(f"{number:.{precision}f}")
```

Результат:

```text
3.142
```

## Фигурные скобки как обычные символы

Чтобы вывести фигурную скобку как часть текста, её необходимо удвоить:

```python
print(f"{{value}}")
```

Результат:

```text
{value}
```

## Особенности

F-строка вычисляется во время выполнения программы.

```python
number = 10
text = f"{number}"

number = 20

print(text)
```

Результат:

```text
10
```

Строка `text` была создана в тот момент, когда `number` имел значение `10`. Последующее изменение переменной не изменяет уже созданную строку.

Спецификаторы форматирования не обязательно учить наизусть. Достаточно понимать общую структуру и помнить, что Python поддерживает настройку:

- точности;
- ширины;
- выравнивания;
- заполнения;
- знака;
- разделителей разрядов;
- процентов;
- систем счисления.

## Преобразования

После выражения внутри f-строки можно поставить восклицательный знак и указать способ преобразования значения.

Поддерживаются:

- `!s` — вызывает `str()`;
- `!r` — вызывает `repr()`;
- `!a` — вызывает `ascii()`.

Общая запись:

```python
f"{expression!conversion}"
```

Эти преобразования существовали до Python 3.12. В Python 3.12 был расширен общий синтаксис выражений внутри f-строк, но сами `!s`, `!r` и `!a` не появились в этой версии.

## `!s`

`!s` использует строковое представление объекта через `str()`.

```python
text = "привет"

print(f"{text!s}")
```

Результат:

```text
привет
```

Фактически это аналогично:

```python
print(str(text))
```

## `!r`

`!r` использует служебное представление объекта через `repr()`.

```python
text = "привет"

print(f"{text!r}")
```

Результат:

```text
'привет'
```

В представлении видны кавычки, поскольку отображается форма, предназначенная прежде всего для разработчика.

Особенно заметна разница на строках со специальными символами:

```python
text = "Hello\nPython"

print(f"{text!s}")
print(f"{text!r}")
```

Результат:

```text
Hello
Python
'Hello\nPython'
```

При `!s` перенос строки выполняется, а при `!r` его запись `\n` остаётся видимой.

## `!a`

`!a` использует функцию `ascii()`.

```python
text = "привет"

print(f"{text!a}")
```

Результат будет выглядеть примерно так:

```text
'\u043f\u0440\u0438\u0432\u0435\u0442'
```

Символы вне ASCII заменяются escape-последовательностями Unicode.

Это не байты. Результатом f-строки по-прежнему является объект типа `str`.

```python
text = "привет"
result = f"{text!a}"

print(type(result))
```

Результат:

```text
<class 'str'>
```

## Комбинация преобразования и форматирования

После преобразования можно добавить спецификатор форматирования:

```python
text = "Python"

print(f"{text!r:>12}")
```

Результат:

```text
    'Python'
```

Сначала применяется `repr()`, затем полученная строка выравнивается вправо.

## Отладочный синтаксис с `=`

Начиная с Python 3.8 внутри f-строки можно использовать знак `=` после выражения.

```python
x = 10

print(f"{x=}")
```

Результат:

```text
x=10
```

Python выводит:

1. текст выражения;
2. знак `=`;
3. результат выражения.

Можно использовать полноценные выражения:

```python
a = 10
b = 5

print(f"{a + b=}")
```

Результат:

```text
a + b=15
```

Этот синтаксис удобен при отладке программы.

## Форматирование вместе с `=`

После `=` можно добавить спецификатор форматирования:

```python
x = 10

print(f"{x=:04d}")
```

Результат:

```text
x=0010
```

Другой пример:

```python
pi = 3.14159265

print(f"{pi=:.2f}")
```

Результат:

```text
pi=3.14
```

## Пробелы внутри выражения

Пробелы вокруг выражения перед `=` сохраняются в выводе:

```python
x = 10

print(f"{x = }")
```

Результат:

```text
x = 10
```

Это позволяет управлять читаемостью отладочного вывода.

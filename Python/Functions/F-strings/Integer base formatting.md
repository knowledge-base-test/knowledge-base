Целые числа можно представить в разных системах счисления:

- десятичной;
- двоичной;
- восьмеричной;
- шестнадцатеричной.

Сам объект `int` при форматировании не изменяется. Создаётся строка с другим представлением того же числа.

```python
value = 42

binary_text = f"{value:b}"

print(value)
print(binary_text)
print(type(binary_text))
```

Результат:

```text
42
101010
<class 'str'>
```

## Двоичная система

Спецификатор `b` представляет целое число в двоичной системе.

```python
value = 42

print(f"{value:b}")
```

Результат:

```text
101010
```

Спецификатор `#b` добавляет префикс `0b`:

```python
print(f"{value:#b}")
```

Результат:

```text
0b101010
```

## Восьмеричная система

Спецификатор `o` представляет число в восьмеричной системе:

```python
value = 42

print(f"{value:o}")
```

Результат:

```text
52
```

Спецификатор `#o` добавляет префикс `0o`:

```python
print(f"{value:#o}")
```

Результат:

```text
0o52
```

## Шестнадцатеричная система

Спецификатор `x` использует строчные буквы:

```python
value = 42

print(f"{value:x}")
```

Результат:

```text
2a
```

Спецификатор `#x` добавляет префикс `0x`:

```python
print(f"{value:#x}")
```

Результат:

```text
0x2a
```

Спецификатор `X` использует заглавные буквы:

```python
value = 255

print(f"{value:X}")
print(f"{value:#X}")
```

Результат:

```text
FF
0XFF
```

## Числовые литералы

В коде целое число также можно записать в разных системах счисления:

```python
binary_value = 0b101010
octal_value = 0o52
hex_value = 0x2A

print(binary_value)
print(octal_value)
print(hex_value)
```

Результат:

```text
42
42
42
```

Все три переменные получают объекты типа `int` с одинаковым числовым значением.

Префиксы определяют только способ записи числового литерала в исходном коде:

- `0b` — двоичный;
- `0o` — восьмеричный;
- `0x` — шестнадцатеричный.

## Ведущие нули и ширина

Спецификаторы систем счисления можно сочетать с шириной и заполнением нулями:

```python
value = 42

print(f"{value:08b}")
print(f"{value:04x}")
```

Результат:

```text
00101010
002a
```

При использовании префикса:

```python
print(f"{value:#010b}")
```

Результат:

```text
0b00101010
```

Общая ширина включает префикс `0b`.

## Разделители групп

Для двоичных, восьмеричных и шестнадцатеричных представлений удобно использовать подчёркивания:

```python
value = 65535

print(f"{value:_b}")
print(f"{value:_x}")
```

Результат:

```text
1111_1111_1111_1111
ffff
```

Группировка зависит от выбранного типа представления.

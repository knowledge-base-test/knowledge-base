Числовые спецификаторы определяют, как числа будут представлены внутри f-строки.

Общая запись:

```python
f"{value:specifier}"
```

## Целые числа

Спецификатор `d` представляет значение как десятичное целое число.

```python
value = 42

print(f"{value:d}")
```

Результат:

```text
42
```

Для обычных целых чисел `d` часто можно не указывать:

```python
print(f"{value}")
```

Результат будет тем же:

```text
42
```

## Ведущие нули

Число перед `d` задаёт минимальную ширину поля, а `0` указывает заполнять свободное место нулями.

```python
value = 42

print(f"{value:04d}")
```

Результат:

```text
0042
```

Разбор:

- `0` — использовать нули для заполнения;
- `4` — итоговая минимальная ширина;
- `d` — десятичное целое число.

Если число уже длиннее указанной ширины, оно не обрезается:

```python
value = 12345

print(f"{value:04d}")
```

Результат:

```text
12345
```

## Числа с фиксированной точкой

Спецификатор `f` представляет число в виде десятичной дроби.

```python
pi = 3.14159265

print(f"{pi:f}")
```

Результат:

```text
3.141593
```

По умолчанию после точки выводится шесть знаков.

## Количество знаков после точки

Запись `.2f` означает, что после точки необходимо оставить два знака.

```python
pi = 3.14159265

print(f"{pi:.2f}")
```

Результат:

```text
3.14
```

Это форматирование выполняет округление отображаемого значения.

```python
number = 3.146

print(f"{number:.2f}")
```

Результат:

```text
3.15
```

Исходный объект при этом не изменяется:

```python
number = 3.146

text = f"{number:.2f}"

print(number)
print(text)
```

Результат:

```text
3.146
3.15
```

Переменная `number` продолжает ссылаться на исходный объект `float`, а f-строка создаёт новый объект `str`.

Спецификатор `f` можно использовать и с целыми числами:

```python
value = 42

print(f"{value:.2f}")
```

Результат:

```text
42.00
```

## Общая ширина числа

Число перед точкой задаёт минимальную ширину всего поля.

```python
pi = 3.14159265

print(f"{pi:8.2f}")
```

Результат:

```text
    3.14
```

Поле имеет ширину 8 символов:

```text
[ ][ ][ ][ ]3.14
```

Числа по умолчанию выравниваются по правому краю.

## Проценты

Спецификатор `%`:

1. умножает значение на `100`;
2. добавляет знак `%`.

```python
value = 0.1234

print(f"{value:%}")
```

Результат:

```text
12.340000%
```

Точность можно ограничить:

```python
print(f"{value:.2%}")
```

Результат:

```text
12.34%
```

Значение `0.1234` при этом не изменяется. Форматируется только его представление внутри новой строки.

## Ограничение длины строки

Для строк число после точки задаёт максимальное количество отображаемых символов.

```python
text = "Python"

print(f"{text:.3}")
```

Результат:

```text
Pyt
```

Это не изменяет исходную строку:

```python
text = "Python"
short_text = f"{text:.3}"

print(text)
print(short_text)
```

Результат:

```text
Python
Pyt
```

## Символ по числовому коду

Спецификатор `c` преобразует целое число в соответствующий символ Unicode.

```python
print(f"{65:c}")
```

Результат:

```text
A
```

Число `65` является кодовой точкой символа `A`.

Другой пример:

```python
print(f"{9731:c}")
```

Результат:

```text
☃
```

## Комбинированный пример

```python
for i in range(1, 6):
    print(f"{i:>2} * {i:>2} = {i * i:>3}")
```

Результат:

```text
 1 *  1 =   1
 2 *  2 =   4
 3 *  3 =   9
 4 *  4 =  16
 5 *  5 =  25
```

Здесь ширина полей используется для создания ровных столбцов.

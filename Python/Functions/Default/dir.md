`dir()` — встроенная функция Python, которая отображает список имен, доступных в текущей области видимости или принадлежащих определённому объекту.

Синтаксис:

```python
dir()
```

или

```python
dir(object)
```

## Как работает

Если вызвать функцию без аргументов:

```python
dir()
```

она вернёт список всех имен, доступных в текущем файле (точнее, в текущей области видимости). Это могут быть:

- переменные;
- функции;
- импортированные модули;
- другие объекты.

Например:

```python
name = "Danil"
age = 21

print(dir())
```

В результате среди имен будут `name` и `age`.

---

Если передать объект:

```python
dir(object)
```

функция вернёт список имен, относящихся к этому объекту.

Например:

```python
text = "Hello"

print(dir(text))
```

или

```python
import math

print(dir(math))
```

В результате будет выведен список методов, функций и других имен, принадлежащих объекту или модулю.

## Особенности

`dir()` возвращает объект типа `list`.

Эта функция часто используется для изучения новых модулей, объектов и их возможностей без необходимости открывать документацию.

`print()` — встроенная функция для вывода данных в консоль.

## Синтаксис

```python
print(*objects, sep=" ", end="\n")
```

Аргументы функции перечисляются через запятую.

## Параметры

- `sep` — разделитель между аргументами. По умолчанию `" "` (пробел).
- `end` — символ или строка, которой заканчивается вывод. По умолчанию `"\n"` (перенос строки).

Значения параметров `sep` и `end` задаются строками в двойных (`""`) или одинарных (`''`) кавычках.

## Примеры

```python
print("Hello", "World")
# Hello World

print("Hello", "World", sep="-")
# Hello-World

print("Hello", end=" ")
print("World")
# Hello World
```

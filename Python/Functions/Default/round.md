`round()` — встроенная функция Python, которая используется для округления чисел.

Общий синтаксис:

```python
round(number, ndigits)
```

- `number` — число, которое нужно округлить.
- `ndigits` — количество знаков после запятой, которое нужно оставить.

В оба аргумента можно передавать:
- литералы;
- переменные;
- выражения.

Например:

```python
round(3.14159, 2)

number = 3.14159
round(number, 3)

round(10 / 3, 4)
```

---

## Как работает

Если указать второй аргумент, число будет округлено до указанного количества знаков после запятой.

```python
print(round(3.14159, 2))
```

Результат:

```text
3.14
```

Если второй аргумент не указать, число округляется до ближайшего целого числа.

```python
print(round(3.8))
```

Результат:

```text
4
```

При этом возвращается объект типа `int`.

---

## Особенности

Функция `round()` использует **банковское округление**.

Если число находится ровно посередине между двумя целыми, выбирается ближайшее **чётное** число.

Например:

```python
print(round(2.5))
print(round(3.5))
```

Результат:

```text
2
4
```

Это сделано для уменьшения накопления ошибок при большом количестве вычислений.

Также следует помнить, что [[Неизменяемые типы данных]] `float` хранятся в памяти в двоичном виде. Многие десятичные дроби невозможно представить абсолютно точно, поэтому иногда результат округления может оказаться неожиданным.

Например:

```python
print(round(2.675, 2))
```

Результат:

```text
2.67
```

Хотя интуитивно можно ожидать `2.68`.

Это связано не с ошибкой функции `round()`, а с особенностями хранения чисел типа `float`.

Если необходимы максимально точные десятичные вычисления (например, в финансовых расчётах), вместо `float` используют специальные типы данных, которые хранят десятичные числа без подобных ошибок.

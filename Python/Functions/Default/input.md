`input()` — встроенная функция Python, которая получает данные, введённые пользователем в терминале.

Синтаксис:

```python
input()
```

В круглых скобках можно указать строку-приглашение, которая отобразится перед вводом:

```python
input("Введите имя: ")
```

## Как работает

Во время выполнения `input()` программа останавливается и ожидает, пока пользователь введёт данные и нажмёт `Enter`.

```python
name = input("Введите имя: ")

print(name)
```

Пример в терминале:

```text
Введите имя: Данил
Данил
```

Функция всегда возвращает введённые данные как значение типа `str`, даже если пользователь ввёл число:

```python
age = input("Введите возраст: ")

print(type(age))
```

При вводе `21` результатом будет:

```text
<class 'str'>
```

Для вычислений строку необходимо преобразовать в числовой тип:

```python
age = int(input("Введите возраст: "))

print(age + 1)
```

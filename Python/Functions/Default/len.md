`len()` — встроенная функция Python, которая определяет длину объекта.

Для строк длина измеряется количеством символов.

Синтаксис:

```python
len(x)
```

где `x` — объект, длину которого необходимо определить.

## Как работает

Для строки функция возвращает количество символов.

Например:

```python
text = "Python"

print(len(text))
```

Результат:

```text
6
```

Пробелы также считаются символами:

```python
print(len("Hello world"))
```

Результат:

```text
11
```

Пустая строка имеет длину 0:

```python
print(len(""))
```

Результат:

```text
0
```

Можно передавать строковый литерал, переменную или результат работы другой функции:

```python
print(len("Programming"))

name = input("Введите имя: ")

print(len(name))
```

## Особенности

`len()` возвращает значение типа `int`.

Функция работает не только со строками, но и со многими другими объектами Python, которые имеют длину (например, списками, кортежами, словарями и множествами).

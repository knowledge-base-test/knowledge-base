`type()` — встроенная функция Python, которая определяет тип переданного объекта.

Синтаксис:

```python
type(x)
```

где `x` — объект, тип которого необходимо определить.

## Как работает

В функцию можно передавать значения напрямую:

```python
print(type(10))
print(type(3.14))
print(type("Hello"))
print(type(True))
```

Результат:

```text
<class 'int'>
<class 'float'>
<class 'str'>
<class 'bool'>
```

Также можно передавать переменные и выражения:

```python
number = 10

print(type(number))
print(type(number / 2))
```

Результат:

```text
<class 'int'>
<class 'float'>
```

Функция `type()` возвращает не строку с названием типа, а сам объект, представляющий класс этого значения.

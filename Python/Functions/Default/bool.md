`bool` — логический тип данных в Python. Он может принимать только два значения:

- `True`
- `False`

Для преобразования значений в логический тип используется встроенная функция `bool()`.

Синтаксис:

```python
bool(x)
```

## Как работает

Функция определяет, является ли переданное значение истинным (`True`) или ложным (`False`).

### Для чисел

У целых чисел (`int`) все значения считаются `True`, кроме нуля.

```python
print(bool(10))
print(bool(-5))
print(bool(1))
print(bool(0))
```

Результат:

```text
True
True
True
False
```

То же правило действует и для `float`:

```python
print(bool(3.14))
print(bool(-0.5))
print(bool(0.0))
```

Результат:

```text
True
True
False
```

---

### Для строк

Любая непустая строка считается `True`.

```python
print(bool("Hello"))
print(bool("0"))
print(bool("False"))
print(bool(" "))
```

Результат:

```text
True
True
True
True
```

Даже строка, содержащая только пробел, является непустой, поэтому её логическое значение — `True`.

Только пустая строка считается `False`:

```python
print(bool(""))
```

Результат:

```text
False
```

## Особенности

`bool()` возвращает значение типа `bool`.

Этот тип широко используется в условиях (`if`, `while`) и логических выражениях.

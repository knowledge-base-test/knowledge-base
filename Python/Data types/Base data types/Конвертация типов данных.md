Конвертация типов данных — это процесс преобразования значения одного типа данных в другой.

В Python для этого используются встроенные функции:

- `str()`
- `int()`
- `float()`

---

# str

## Что это

`str()` преобразует переданное значение в строку (`str`).

Синтаксис:

```python
str(x)
```

## Как работает

Можно преобразовать практически любой встроенный тип данных:

```python
print(str(10))
print(str(3.14))
print(str(True))
```

Результат:

```text
10
3.14
True
```

После преобразования результат имеет тип `str`:

```python
number = 10

text = str(number)

print(type(text))
```

Результат:

```text
<class 'str'>
```

# int

## Что это

`int()` преобразует значение в целое число (`int`).

Синтаксис:

```python
int(x)
```

## Как работает

### Из строки

Строку можно преобразовать только тогда, когда она содержит запись целого числа:

```python
print(int("15"))
```

Результат:

```text
15
```

Если строка содержит дробное число:

```python
int("15.7")
```

или текст:

```python
int("Hello")
```

будет вызвана ошибка.

### Из числа с плавающей точкой

При преобразовании `float` в `int` дробная часть **просто отбрасывается**, без округления.

```python
print(int(8.9))
print(int(8.1))
print(int(-3.8))
```

Результат:

```text
8
8
-3
```

# float

## Что это

`float()` преобразует значение в число с плавающей точкой (`float`).

Синтаксис:

```python
float(x)
```

## Как работает

### Из целого числа

Целое число преобразуется без потери данных:

```python
print(float(10))
```

Результат:

```text
10.0
```

### Из строки

Строку можно преобразовать только тогда, когда она содержит корректную запись числа.

Например:

```python
print(float("15"))
print(float("3.14"))
```

Результат:

```text
15.0
3.14
```

Дробная часть должна быть записана через **точку**, а не через запятую.

Например:

```python
float("3,14")
```

вызовет ошибку.

Также ошибку вызовет попытка преобразовать строку, которая не является числом:

```python
float("Hello")
```

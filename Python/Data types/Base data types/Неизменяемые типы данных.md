Неизменяемые (immutable) типы данных нельзя изменить после создания объекта. При изменении создаётся новый объект.

## Типы

- `str` — строка (текст).

```python
text = "Hello"
```

- `int` — целые числа без ограничений по длине.

```python
number = 125
```

При обычном делении (`/`) результат имеет тип `float`.

```python
10 / 2
# 5.0
```

- `float` — числа с плавающей точкой (дробные числа).

```python
pi = 3.14
```

Совместим с типом `int` в арифметических операциях.

- `bool` — логический тип данных. Принимает только два значения: `True` и `False`.

```python
is_student = True
```

Используется для управления поведением программы.

- `NoneType` — обозначает отсутствие значения.

```python
value = None
```

Часто используется как заглушка или признак отсутствия результата.

- `complex` — комплексные числа.

```python
z = 3 + 4j
```

- `bytes` — неизменяемая последовательность байтов.

```python
data = b"Hello"
```

## Особенности

Строку (`str`) можно умножить на целое число (`int`), чтобы повторить её несколько раз.

```python
"Hi" * 3
# 'HiHiHi'
```

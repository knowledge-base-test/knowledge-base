Составные типы данных могут содержать несколько элементов, в том числе другие составные типы данных.

## Неизменяемые

- `tuple` — кортеж. Может содержать любые типы данных, включая другие составные типы, но после создания не может быть изменён.

```python
point = (10, 20)
```

## Изменяемые

- `list` — список.

```python
numbers = [1, 2, 3]
```

- `dict` — словарь, состоящий из пар **ключ : значение**.

```python
student = {
    "name": "Danil",
    "age": 21
}
```

- `set` — множество, содержащее только уникальные элементы.

```python
numbers = {1, 2, 2, 3}
# {1, 2, 3}
```

В отличие от `list`, одинаковые элементы автоматически удаляются.

- `bytearray` — изменяемая последовательность байтов.

```python
data = bytearray(b"Hello")
```

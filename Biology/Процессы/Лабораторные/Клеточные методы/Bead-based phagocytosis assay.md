Bead-based phagocytosis assay — метод количественной оценки [[Phagocytosis|фагоцитоза]] с использованием искусственных микросфер, которые служат модельными частицами.

Частицы обычно:

- имеют известный размер;
- содержат флуорофор;
- могут быть покрыты белками;
- могут быть опсонизированы антителами.

После инкубации с клетками их поглощение можно оценивать с помощью проточной цитометрии или микроскопии.

## Принцип

Флуоресцентные микросферы добавляют к клеткам, способным к фагоцитозу.

После инкубации частицы могут:

- оставаться свободными;
- связываться с поверхностью клетки;
- быть интернализированы.

Основная экспериментальная задача — отличить **связанные с поверхностью частицы** от действительно [[Phagocytosis|фагоцитированных]].

## Опсонизация

Для исследования Fc-рецептор-зависимого фагоцитоза микросферы можно покрывать антигеном, а затем специфическими антителами.

Антитело связывается с антигеном Fab-участками, тогда как Fc-область остаётся доступной для взаимодействия с Fc-рецепторами фагоцита.

Таким образом, система моделирует опсонизированную частицу.

## Определение интернализации

Если частицы флуоресцентные, их собственный сигнал показывает наличие частицы у клетки, но сам по себе не позволяет определить, находится она внутри клетки или связана с её поверхностью.

Один из подходов — дополнительное окрашивание антителом, которое связывает только доступные снаружи частицы.

В таком случае:

- собственная флуоресценция частицы + внешнее окрашивание → частица находится на поверхности;
- собственная флуоресценция частицы без внешнего окрашивания → частица интернализирована.

Этот подход работает только при условиях, когда вторичное антитело не проникает через неповреждённую клеточную мембрану.

## Контроль с ингибированием актина

[[Phagocytosis|Фагоцитоз]] является актин-зависимым процессом.

Поэтому соединения, нарушающие полимеризацию актина, например цитохалазин D, могут использоваться как функциональный отрицательный контроль.

При эффективном ингибировании актина количество интернализированных частиц должно снижаться.

## Анализ методом проточной цитометрии

Типичная стратегия включает:

1. Выделение интересующей клеточной популяции по параметрам светорассеяния.
2. Исключение клеточных агрегатов и анализ одиночных клеток.
3. Определение клеток, ассоциированных с флуоресцентными частицами.
4. Разделение поверхностно связанных и интернализированных частиц.

В зависимости от задачи могут анализироваться:

- процент клеток, поглотивших частицы;
- интенсивность флуоресценции;
- распределение клеток по количеству захваченных частиц.

## Контроли

Необходимы как минимум:

- клетки без микросфер;
- неопсонизированные микросферы;
- опсонизированные микросферы;
- контроль внешнего флуоресцентного окрашивания;
- контроль ингибирования фагоцитоза.

Дополнительные контроли зависят от используемых флуорофоров и дизайна эксперимента.

## Ограничения

Микросферы являются искусственной моделью и не полностью воспроизводят свойства биологических объектов.

Результат зависит от:

- размера частиц;
- химии их поверхности;
- плотности опсонинов;
- типа клеток;
- экспрессии соответствующих рецепторов;
- времени инкубации;
- отношения количества частиц к числу клеток.

Поэтому параметры assay должны быть стандартизированы внутри конкретного эксперимента.
